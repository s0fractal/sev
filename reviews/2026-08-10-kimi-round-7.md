## Findings

### P1-1: `RecursionError` escapes the raw-byte boundary — the parser is not total

`parse_strict(b"[" * 500 + b"]" * 500)` raises `RecursionError` out of
`json.JSONDecoder.raw_decode` (snapshot_model.py:171). Only `_DupKey` and
`ValueError` are caught; `RecursionError` is neither. The same escapes
`parse_snapshot`, and — confirmed end-to-end — `validate_warrant_receipt`
when a CAS record's committed bytes are deeply nested JSON
(`_resolve_record` → `parse_strict`, snapshot_model.py:1080): the "total"
composed verdict crashes with a host exception on hostile evidence bytes.
`_scan_surrogates` and `jcs` recurse unguarded too (same class; the JSON
scanner merely trips first).

This contradicts the contract stated in the spec header ("hostile shapes →
findings, never host exceptions") and the model docstring, and it is exactly
the input class `_freeze`'s `MAX_FREEZE_DEPTH` exists for — the byte layer
has no equivalent. The fuzz vector only generates depth ≤ 4, so the suite
cannot see it.

*Fix direction:* bound depth at the byte boundary (catch `RecursionError`
in `parse_strict` → a named refusal, e.g. `OVER_DEPTH`), add a model vector
and a conformance fixture; the conformance fixture set then also pins the
refusal for second implementations.

### P1-2: codepoint `sorted()` where the normative order is UTF-16

`sev_projector.py:356`: `unjudged = sorted(w["protocol"] ...)` sorts by
codepoint. Verified divergence: `[chr(0x10000), chr(0xE000)]` sorts
`[U+E000, U+10000]` by codepoint but `[U+10000, U+E000]` by UTF-16.
`unjudged_subroots` lands in the JCS-serialized `view_manifest`, and the
`L-UNJUDGED` note joins the same list into `loss_manifest` (digest-bound via
`loss_manifest_digest`) — so two honest implementations (Python vs a
UTF-16-sorter) emit different manifest bytes and different digests for
astral protocol names. This is the exact class spec rev 3 fixed for
`universe` ordering ("one ordering serves the whole format"). Same exposure
in `Graph.nquads()` (`sorted(self.quads)`, sev_projector.py:89): quad lines
embed literals that can carry astral paths, and `graph_digest` binds the
resulting byte order.

*Fix direction:* sort with `path_sort_key` (or a UTF-16 line key); or
declare protocol names ASCII in the spec and enforce it in
`validate_snapshot`. Either way, file the disagreement as a vector first,
per house rule 4.
