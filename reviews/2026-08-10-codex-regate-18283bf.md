## P1-1 — nested receipt entries were not bound to the envelope bytes

The validator re-derived the WarrantID and checked every reason the receipt
*chose to include*, but proved nothing about completeness or provenance of
`signatures[]` and `reasons[]`. Reproduced, all with **zero findings**:

- an envelope carrying one signature, reported as `signatures: []` — which
  was the state of the shipped fixture, so `coverage.not_emitted` did not
  even mention `signature` and `L-NOSIG` never fired;
- a committed check reason with `reasons: []` — graph and coverage silently
  lose the reason and its run;
- a **fabricated** `valid: true, binding: "bound"` signature for actor
  `fabricated`, present nowhere in the envelope.

So a clean receipt could both hide and invent evidence, and every
"dataset-relative" statement built on it meant only *relative to what the
receipt chose to disclose*. This outranked the earlier coverage defect.

**Disposition.** Exact bijections against the already-parsed committed
bytes, in `_bind_to_envelope`:

- `envelope_signature_entries()` derives `(sig_digest, multiplicity, actor,
  key)` from `sigs[]` in envelope order; the receipt must match that
  multiset exactly, with `actor`/`key` agreeing — `SIGNATURE_MISSING`,
  `SIGNATURE_NOT_IN_ENVELOPE`, `SIGNATURE_FIELD_MISMATCH`,
  `DUPLICATE_SIGNATURE_ENTRY`;
- `reportable_reason_pointers()` derives every committed `kind:"check"`
  pointer; the receipt must account for exactly those, one each —
  `REASON_MISSING`, `REASON_NOT_COMMITTED`, `DUPLICATE_REASON_POINTER`;
- prose reasons are **not** demanded (they carry no runtime and are not
  re-executed) — a permanent vector fixes that boundary.

Eight refusal vectors. The binding immediately caught the shipped
fixtures — every one of them was hiding its envelope signature — and they
were corrected rather than exempted.

## P1-2 — the node budget counted only containers

`_freeze` charged the budget after the primitive early-return, so a
million-element scalar list cost one node and the declared ceiling never
fired; `[0] * (MAX_FREEZE_NODES + 1)` was copied whole and only later
rejected as `NOT_OBJECT`.

**Disposition.** Every visited value is charged **before** any return, dict
keys are nodes too, and a separate `MAX_FREEZE_BYTES` budget bounds string
payload — a node count bounds shape, not memory. Vectors: a wide scalar
list exhausts the node budget (a small list is still refused on *shape*,
proving the vector isolates the budget rather than the type check), and an
oversized string payload exhausts the byte budget.
